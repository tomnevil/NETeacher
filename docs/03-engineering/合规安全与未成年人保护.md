# 合规安全与未成年人保护

> 对应 PLAN 第五部分「合规与安全」，并满足本期「Web 优先 + 未成年人产品」的合规基线。

## 1. 法规依据
- 《个人信息保护法》《未成年人网络保护条例》《网络安全法》。
- 教育类内容：课标对齐、内容审核与版权（PLAN 五）。
- 等保与备案：上线前完成 ICP 备案；用户超阈值按等保 2.0 二级（M2 评估三级）。

## 2. 隐私保护
- **数据最小化**：仅收集教学必要信息；手机号加密、PII 脱敏展示（好友榜仅昵称+积分，见 `FR-ACC-007`）。
- **家长控制权**：绑定家长手机号（强制，`FR-ACC-002`）；家长可导出/删除孩子数据（`FR-ACC-010`）。
- **不共享**：学习记录不向第三方共享（PLAN 五）。
- **数据生命周期**：学习行为日志按冷热分层，超期归档/删除。

## 3. 内容合规
- 课程内容经教育专家审核，避免文化偏见、不当价值观（`FR-OPS-007`）。
- 音视频资源版权授权或自研（PLAN 五）。

## 4. 防沉迷机制（本期强制）
| 需求 | 实现 |
| --- | --- |
| 单次时长提醒 | 连续学习 30 分钟弹休息提示（前端定时+后端校验，`FR-OPS-009`） |
| 每日学习上限 | 家长设置（如 ≤60 分钟），达限锁学习功能（`FR-OPS-010`、`FR-TRK-007`） |
| 时段锁 | 家长设学习时段锁，非时段禁无关功能 |

## 5. 安全设计
- 传输 TLS1.2+；鉴权 JWT + 网关校验（`API接口规范.md`）。
- 越权防护：所有 childId/classId 资源校验归属。
- 渗透测试：上线前第三方渗透测试（PLAN 六 交付物 2）。

## 6. 审计与留存
- 账号绑定、注销、内容审核、升降级触发均留痕，满足合规追溯。
- 操作日志独立存储，权限最小化访问。
