# 数据字典

> 核心数据实体（DE）与表结构。存储选型见 `技术选型对比与决策.md` §4。本字典为接口与研发的契约基线。

## 实体索引（DE）

| 编号 | 实体 | 存储 | 说明 |
| --- | --- | --- | --- |
| DE-001 | user 用户 | MySQL | 统一账号（学生/家长/教师/运营） |
| DE-002 | parent_bind 家长绑定 | MySQL | 学生↔家长绑定（合规） |
| DE-003 | student_profile 学生画像 | MySQL | 年级、目标、初始级别、严格度 |
| DE-004 | course_level 课程级别 | MySQL | L1-L6 词汇量/语法/能力目标 |
| DE-005 | course 课程 | MySQL | 主修/拓展/专项，元数据+资源引用 |
| DE-006 | lesson 课时 | MySQL | 课程下单元课时，时长/类型 |
| DE-007 | word 单词 | MySQL | 词面、音标、图/音/景资源引用 |
| DE-008 | quiz 题目 | MySQL | 客观/主观题、知识点关联 |
| DE-009 | unit_test 单元测 | MySQL | 单元→测评绑定 |
| DE-010 | exam_result 测评结果 | MySQL | 成绩、雷达图、报告引用 |
| DE-011 | learning_record 学习记录 | MongoDB | 行为日志、答题流水、录音元数据 |
| DE-012 | progress 进度 | MySQL | 课程/关卡完成度、掌握度 |
| DE-013 | points_ledger 积分流水 | MySQL | 积分增减（Outbox 保证一致） |
| DE-014 | badge 勋章 | MySQL | 成就解锁 |
| DE-015 | knowledge_node/edge 知识点 | MySQL | 知识图谱 DAG |
| DE-016 | recommendation 推荐结果 | Redis/MySQL | 推荐包/路径快照 |

## 关键表结构（节选）

### DE-001 user
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | BIGINT PK | 用户 ID |
| user_type | TINYINT | 1学生 2家长 3教师 4运营 |
| phone | VARCHAR(20) | 手机号（加密） |
| wx_openid | VARCHAR(64) | 微信绑定 |
| status | TINYINT | 0游客 1已绑定 2正常 9注销中 |
| created_at | DATETIME | — |

### DE-002 parent_bind
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| student_id | BIGINT FK | 学生 |
| parent_id | BIGINT FK | 家长 |
| confirm_status | TINYINT | 0待确认 1已确认 |
| bound_at | DATETIME | — |

### DE-003 student_profile
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| student_id | BIGINT FK | — |
| grade | TINYINT | 1-9 年级 |
| goal | VARCHAR(32) | 小升初冲刺/提升口语… |
| init_level | TINYINT | L1-L6 |
| eval_strictness | TINYINT | 1宽松 2标准 3严格 |

### DE-004 course_level
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| level | TINYINT | L1-L6 |
| vocab_target | INT | 词汇量目标 |
| grammar_json | JSON | 语法点 |
| cefr | VARCHAR(8) | CEFR 子级 |

### DE-007 word
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | BIGINT PK | — |
| spelling | VARCHAR(64) | 词面 |
| phoneme | VARCHAR(64) | 音标 |
| img_url | VARCHAR(255) | 图像（COS） |
| scene_video_url | VARCHAR(255) | 情景视频 |
| level | TINYINT | 所属级别 |

### DE-011 learning_record（MongoDB 文档）
```json
{
  "userId": "long",
  "type": "word|grammar|speaking|listening|dialogue",
  "lessonId": "long",
  "answer": "object",
  "score": "float",
  "audioMeta": { "cosKey": "string", "duration": "int" },
  "ts": "datetime"
}
```

### DE-015 knowledge_node / knowledge_edge
| node 字段 | 说明 |
| --- | --- |
| id, name, level | 知识点 |
| edge 字段 | src_id, dst_id, relation（先修） |

> 完整字段与索引以研发设计评审后落地 Schema 为准；本字典为 PRD 阶段契约。
