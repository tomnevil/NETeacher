# 质量与测试策略

> 测试分层 + 端到端验收用例 + Definition of Done（DoD）。

## 1. 测试分层
| 层级 | 范围 | 工具（建议） |
| --- | --- | --- |
| 单元 | 服务/组件逻辑 | JUnit / Vitest |
| 集成 | 模块间/接口 | Postman / TestContainers |
| 端到端 | 核心用户链路 | Playwright（Web/H5） |
| 性能 | 评测延迟/首屏 | k6 / Lighthouse |
| 合规 | 防沉迷/越权/删除 | 专项用例 |

## 2. 端到端验收用例（核心链路）
| 用例 | 步骤 | 预期 |
| --- | --- | --- |
| E2E-01 注册到学习 | 注册→绑家长→定级→学1课→完成 | 进度更新、仪表盘可见 |
| E2E-02 口语评测 | 跟读→提交→等待 | 实时分≤1s，报告含音素高亮 |
| E2E-03 单元测闭环 | 学满5课时→单元测→提交 | 客观题自动判分，成绩入报告 |
| E2E-04 家长管控 | 家长设时段锁/每日上限 | 学生端达限进入休息态 |
| E2E-05 未绑定拦截 | 未绑家长学第4节 | 阻断并引导注册（游客3节） |
| E2E-06 数据删除 | 家长发起注销 | 冷静期后数据删除/脱敏 |

## 3. Definition of Done（DoD）
- 功能：满足 `FR-*` 验收标准（AC1/AC2…）。
- 代码：通过评审、单测覆盖≥60%、无高危漏洞。
- 性能：满足 `非功能需求与性能指标.md` 预算。
- 合规：防沉迷/家长绑定/越权/删除用例通过。
- 文档：接口与数据字典同步更新。

## 4. 质量门禁
- 合并 `main` 前：CI 全绿、覆盖率不降、SAST 无高危。
- 发布前：渗透测试 + 性能压测 + 合规验收。
