# 里程碑与迭代计划

> 配合 `PRD-主文档.md` §6 版本范围与 `范围边界与里程碑概览.md` §5。本期纯文档交付；以下为产品工程落地排期（供后续开发参考）。

## 1. 总体节奏
- 采用 2 周一迭代（Sprint）；里程碑以需求范围（M1/M2/M3）而非固定周数硬性切割。

| 里程碑 | 周期（估） | 主题 | 关键交付 |
| --- | --- | --- | --- |
| M1 | W1-W8 | MVP 学练测评闭环 | 账号+家长绑定、分级课程+定级、四学习模块、单元测、仪表盘、家长报告/时段锁、防沉迷 |
| M2 | W9-W16 | 个性化与评测深化 | 升降级、对话训练、阶段测+雷达图、知识图谱、路径推荐、学习地图、成长体系、会员、审核 |
| M3 | W17-W26 | 社交与 B 端 | 社交组队、竞赛、B 端班级平台、运营看板、邀请有礼 |

## 2. M1 双周计划（示例）
| Sprint | 目标 | 范围 |
| --- | --- | --- |
| S1 | 地基 | 脚手架、网关、用户/账号、家长绑定、登录会话 |
| S2 | 课程与定级 | 分级标准、课程元数据、播放器、入学测评 SOE 接入 |
| S3 | 学习四模块 | 单词/语法/听力 + 口语跟读（实时分） |
| S4 | 测评与进度 | 单元测判分、仪表盘、家长报告/时段锁、防沉迷 |
| S5-6 | 打磨与灰度 | 联调、性能预算达标、灰度 10%→50%→100% |

## 3. 发布门禁（Gate）
- 进入下一里程碑前：核心 E2E 用例 100% 通过；性能预算（`非功能需求与性能指标.md`）达标；合规项（防沉迷/家长绑定/数据删除）通过验收。
- 灰度发布：10%→50%→100%，指标（崩溃率/评测成功率/留存）达标后全量。
- 课程/题库内容按周更新，不随版本发版阻塞。

## 4. 依赖与关键路径
- 关键路径：账号/家长绑定 → 入学定级(SOE) → 课程与学习模块 → 单元测 → 仪表盘。
- SOE/LLM 云能力接入为外部依赖，需提前开通与配额申请（见 `技术选型对比与决策.md` §3）。
