## 2. 依赖关系
- M1-4（SOE）依赖腾讯云账号开通与配额；M2-2（LLM）依赖模型选型与部署。
- M1-8 家长端依赖 M1-2 绑定关系；M2-4 推荐依赖 M1-5/6 行为数据沉淀。

## 3. 角色分工说明
- FE：Web/H5 一套 React 代码；DS 提供设计稿与规范（`02-ux/*`）。
- BE：Spring Boot 模块化单体，按 `系统架构设计.md` 模块划分。
- AI：SOE/ASR/TTS/LLM 适配器封装与降级策略。
- QA：依据 `质量与测试策略.md` 编写与执行用例。

> 人日含设计评审、联调与自测缓冲；实际以立项后细化估点为基准。
