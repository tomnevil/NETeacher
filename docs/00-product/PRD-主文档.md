## 1. 产品一句话定位

> **NETeacher** 是一款面向 6-15 岁中小学生的 AI 英语学习平台：以「沉浸式场景 + AI 个性化」为主线，帮助学生完成「学—练—测—评—用」闭环，解决**哑巴英语、记忆低效、学习路径同质化**三大痛点。本期以 **Web 端优先**，并兼顾移动端 H5 响应式适配。

## 2. 解决的核心痛点

| 痛点 | 表现 | 产品解法 |
| --- | --- | --- |
| 哑巴英语 | 会写不会说、不敢开口 | AI 口语跟读（音素级评分）+ 对话训练（AI 角色扮演多轮引导） |
| 记忆低效 | 背了就忘、重复无效 | 多模态记忆 + 艾宾浩斯遗忘曲线 + 错误率驱动的复习调度 |
| 路径同质化 | 所有人学一样内容 | 基于画像/学习数据/知识图谱三维的个性化推荐与学习地图 |

## 3. 目标用户与角色分层

### 3.1 学生（核心使用者，6-15 岁）
分三学段：**小学低段（6-8 岁）**、**小学高段（9-11 岁）**、**初中段（12-15 岁）**。
- 核心诉求：有趣、有反馈、有成就感。
- 关键约束：需在家长监督下使用；合规要求绑定家长手机号。

### 3.2 家长（监督与付费决策）
- 核心诉求：看见进度与效果、可控时长、可付费解锁。
- 关键能力：学习报告（周/月）、异常提醒、学习时段锁、每日学习上限、数据导出/删除权。

### 3.3 教师（可选 B 端角色）
- 核心诉求：班级管理、作业布置与完成率统计、薄弱点分布。
- 落地形态：B 端后台/班级管理平台（按年收费合作）。

### 3.4 运营人员（内部）
- 核心诉求：内容编排、审核、数据看板、活动运营。
- 落地形态：运营后台。

## 4. 价值主张与差异化

- **闭环化**：学-练-测-评-用在同一产品内闭环，数据互通驱动个性化。
- **游戏化激励**：闯关、PK、勋章、积分、学习地图，贴合低龄用户特点。
- **AI 个性化**：从「千人一面」到「千人千面」的推荐与纠音。
- **合规友好**：面向未成年人设计隐私保护、防沉迷与家长控制。

## 5. 北极星指标与核心指标

| 类型 | 指标 | 目标（M1 上线后 90 天） |
| --- | --- | --- |
| 北极星 | **周活跃学员人均有效学习时长（分钟）** | ≥ 120 min/周 |
| 核心-学习 | 单元测完成率 | ≥ 70% |
| 核心-效果 | 口语跟读平均分（SOE）月度提升 | ≥ 5 分/月 |
| 核心-留存 | 次周留存率 | ≥ 45% |
| 核心-转化 | 免费→会员转化率 | ≥ 8% |
| 核心-合规 | 未绑定家长手机号的学生账号占比 | = 0% |
