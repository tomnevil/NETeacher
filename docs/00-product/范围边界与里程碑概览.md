# 范围边界与里程碑概览

> 配套 `PRD-主文档.md`。明确本期范围、非目标、PLAN 映射与勘误、各里程碑交付边界。

## 1. 本期范围（In Scope）

- 客户端：**Web 端优先 + 移动端 H5 响应式适配**。
- 角色：学生、家长、教师（B 端）、运营（内部）四类。
- 核心闭环：学（分级课程）→ 练（互动学习五模块）→ 测（单元测/阶段测）→ 评（AI 评测+雷达图）→ 用（对话训练+学习地图）。
- 文档交付：本 `docs/` 全量 PRD 与工程计划（不含业务代码）。

## 2. 本期非目标（Out of Scope）

| 项 | 说明 |
| --- | --- |
| 原生 App（iOS/Android） | 首期不开发，仅规划演进路线 |
| 微信小程序学生端 | 评估放入 M3，首期以 H5 覆盖移动端 |
| 自研发音评测模型 | 依赖云厂商 SOE + 业务规则后处理，重投入后置 |
| 图数据库（Neo4j） | 知识图谱依赖关系用 MySQL 关系表表达 DAG，规模化后再评估 |
| 微服务拆分 | 采用模块化单体，预留拆分缝，不在本期拆 |
| 直播/外教 1v1 实时音视频 | 仅规划「外教体验课」作为高等级特权，实时链路不在本期 |

## 5. 里程碑交付边界

### M1 — MVP（学练测评基础闭环）
**必须交付**：FR-ACC-001~004/009/010、FR-CRS-001~003/006/008、FR-LRN-001/002/005~009、FR-TST-001/002/007、FR-TRK-001/005/007、FR-PTH-002、FR-OPS-003/009/010。
**验收**：学生可注册→绑定家长→入学定级→学完 1 单元→完成单元测→查看仪表盘与家长报告；口语跟读可用并能给出音素级分数。

### M2 — 增强（个性化与评测深化）
**必须交付**：FR-CRS-004/005/007、FR-LRN-003/010~012、FR-TST-003~006、FR-TRK-002~004/006/008、FR-PTH-001/003~006、FR-OPS-001/004/007。
**验收**：能力雷达图、学习地图、个性化推荐上线；会员版与成长体系可用；内容审核流程闭环。

### M3 — 增值/商业（社交与 B 端）
**必须交付**：FR-ACC-006~008、FR-LRN-004、FR-TST-006、FR-TRK-009/010、FR-OPS-002/005/006/008。
**验收**：社交组队打卡、月度竞赛、B 端班级平台与运营看板上线；邀请有礼可用。

## 6. 发布节奏

- 每里程碑一次灰度发布（10% → 50% → 100%），灰度指标达标后全量。
- 课程/题库内容按周更新（热点主题课），不随版本发版阻塞。
- 发布门禁见 `04-delivery/质量与测试策略.md`（DoD）。
