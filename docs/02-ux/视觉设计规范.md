# 视觉设计规范

> 面向 6-15 岁中小学生 + 家长双用户群，采用「童趣明快 + 专业可信」双模态：学生端活泼游戏化，家长/教师端清爽数据化。技术实现基于 React + Tailwind CSS + shadcn/ui，Web 优先、H5 响应式。

## 1. 设计风格
- **学生端**：明亮青蓝渐变为主色、暖橙为强调色；大圆角卡片、柔和投影；卡通 IP 引导形象贯穿全流程；轻量微动效（按钮回弹、积分飞入、勋章翻转、进度条流光）。
- **家长端 / 教师端**：中性灰白底 + 数据图表，减少装饰，突出信息效率。
- 风格关键词：童趣明快、游戏化激励、大圆角卡片、微动效反馈、响应式 H5。

## 2. 色彩系统

| 类别 | 色值 | 用途 |
| --- | --- | --- |
| 主色 Primary | `#3B82F6` / `#0EA5E9` | 主按钮、链接、主色块 |
| 强调 Accent | `#F59E0B` | 积分、激励、关键 CTA |
| 背景 Background | `#F7F9FC` / `#FFFFFF` / `#0F172A`(深色) | 页面/卡片/暗色 |
| 文本 Text | `#1F2937` / `#6B7280` / `#FFFFFF` | 主文/次要/反白 |
| 功能 Functional | `#22C55E`(成功) / `#EF4444`(错误) / `#F59E0B`(警告) / `#6366F1`(信息) | 状态 |
| 音素高亮 | 绿/黄/红 | 口语纠音正确/一般/错误 |

## 3. 字体与排版
- 字体族：`PingFang SC`（无则系统无衬线回退）。
- 标题 32px/700；副标题 20px/600；正文 16px/400。
- 低龄友好：触控目标 ≥44px；关键操作支持语音提示。

## 4. 组件与布局
- 桌面端：顶部主导航 + 左侧学习模块侧栏 + 内容区三栏，最大宽度 1280px。
- 移动端 H5：底部 Tab（首页/学习/测评/成就/我的），单列卡片流，安全区适配。
- 断点：<768 移动（单列、底部导航、手势滑切）；768-1024 平板（两列）；>1024 桌面（三栏）。

## 5. 交互与反馈
- 即时反馈：答题对错用色块+音效；口语评分用环形进度+音素色标；错误弹知识点解释卡。
- 关键操作二次确认；长任务（报告生成）用骨架屏+进度提示，避免白屏焦虑。
- 自动播放受浏览器策略限制时降级为手动点击播放。

## 7. 无障碍与合规视觉
- 满足触控目标 ≥44px、文字对比度 WCAG AA。
- 未成年人界面避免诱导沉迷的强刺激动效；防沉迷提示明显（见 `FR-OPS-009/010`）。
