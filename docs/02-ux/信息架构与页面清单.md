# 信息架构与页面清单

> 设计基线：Web 优先 + 移动端 H5 响应式适配（设计风格见 `视觉设计规范.md`）。

## 1. 四端信息架构

### 1.1 学生端（Web/H5，核心）
```
学生端
├── 首页（今日任务 / 学习地图入口 / 连续打卡）
├── 学习
│   ├── 学习地图（L1-L6 关卡）
│   ├── 课程详情 + 播放器（字幕/复读/变速）
│   └── 专项课 / 拓展课
├── 练习
│   ├── 单词记忆（多模态/闯关）
│   ├── 语法练习（改错/填空）
│   ├── 口语跟读（波形/音素高亮）
│   ├── 听力训练（三步法/变速）
│   └── 对话训练（AI 角色扮演）
├── 测评
│   ├── 单元测 / 阶段测
│   └── 能力雷达图
├── 成就（勋章 / 积分 / 学习地图进度）
└── 我的（个人中心 / 偏好 / 社交 / 设置）
```

### 1.2 家长端（Web / 小程序）
```
家长端
├── 孩子报告（周报 / 月报）
├── 实时同步（进度 / 异常提醒）
├── 管控（学习时段锁 / 每日上限 / 记录详情）
└── 账号（绑定孩子 / 会员 / 数据导出删除）
```

### 1.3 教师端（B 端后台）
```
教师端
├── 班级管理看板
├── 作业布置与统计
└── 薄弱点分布
```

### 1.4 运营后台（内部）
```
运营后台
├── 课程 / 题库编排
├── 内容审核
├── 活动运营（竞赛 / 热点课）
└── 数据看板
```

## 3. 导航与布局策略
- 桌面端：顶部主导航 + 左侧学习模块侧栏 + 内容区三栏，最大宽度 1280px。
- 移动端 H5：底部 Tab（首页/学习/测评/成就/我的），单列卡片流，安全区适配。
- 断点：<768 移动（单列、底部导航、手势切题）；768-1024 平板（两列）；>1024 桌面（三栏）。
- 详见 `视觉设计规范.md`。
