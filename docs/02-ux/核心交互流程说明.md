# 核心交互流程说明

> 覆盖「注册 → 定级 → 选课 → 学习 → 测评 → 推荐」全链路。流程图均用 Mermaid。

## 1. 新用户首日全链路（时序图）

```mermaid
sequenceDiagram
  actor 学生
  actor 家长
  participant Web as 学生端Web/H5
  participant API as API网关
  participant SVC as 业务服务
  participant AI as AI能力层(SOE/LLM)
  participant DB as 数据层

  学生->>Web: 进入(游客)
  Web->>API: 手机号/微信注册
  API->>SVC: 创建账号
  SVC->>DB: 写用户(游客态)
  Web->>家长: 引导绑定家长手机号
  家长->>Web: 短信确认
  Web->>API: 绑定确认
  SVC->>DB: 置已绑定(合规)
  Web->>API: 发起入学测评
  API->>SVC: 测评子任务
  SVC->>AI: 听力/口语(SOE)/词汇
  AI-->>SVC: 子项得分
  SVC->>DB: 写画像+初始级别
  Web->>API: 拉取基础夯实包
  SVC->>DB: 推荐(FR-PTH-002)
  Web-->>学生: 展示学习地图+首课
  学生->>Web: 学习主修课
  Web->>API: 播放/完成事件
  SVC->>DB: 进度/行为日志
```

## 2. 口语跟读实时评分链路

```mermaid
sequenceDiagram
  actor 学生
  participant Web as 学生端
  participant GW as API网关
  participant Eval as 评测服务
  participant SOE as 腾讯云SOE
  participant WS as WebSocket/SSE
  participant DB as 数据层

  学生->>Web: 点击跟读(手势触发录音)
  Web->>Web: 端侧降噪+VAD
  Web->>GW: 音频分片上传
  GW->>Eval: 提交评测
  Eval->>SOE: 实时评测请求
  SOE-->>Eval: 实时分数(准确度)
  Eval->>WS: 推送实时分(P95≤1s)
  WS-->>Web: 环形进度更新
  Eval->>SOE: 异步音素级报告
  SOE-->>Eval: 详细报告(≤10s)
  Eval->>DB: 落库+更新进度(Outbox)
  Eval->>WS: 报告完成
  WS-->>Web: 展示波形+音素高亮
```

## 3. 学习状态机（课程单元）

```mermaid
stateDiagram-v2
  [*] --> 未解锁: 前置未完成
  未解锁 --> 可学: 解锁条件达成
  可学 --> 学习中: 进入课程
  学习中 --> 已学完: 完成播放+小结
  已学完 --> 待测评: 单元5课时满
  待测评 --> 测评中: 进入单元测
  测评中 --> 已通过: 达标
  测评中 --> 待巩固: 未达标
  待巩固 --> 可学: 复习后重测
  已通过 --> 已解锁下一级: 升级(FR-CRS-007)
```


## 5. 异常与边界要点（跨流程）
- 录音中断（iOS 后台切换）：本地缓存音频 → 失败重传 → 仍失败降级文本跟读（见 `FR-LRN-007` E1）。
- SOE 不可用：本地基础分 + 稍后补评提示。
- 未绑定家长手机号：阻断正式课程，仅游客 3 节（见 `FR-ACC-002`）。
- 防沉迷达限：学生端进入休息态，家长可临时调整（见 `FR-OPS-010`）。
- 数据一致性：学习记录-进度-积分通过 Outbox 事件表保证最终一致（见 `系统架构设计.md`）。
